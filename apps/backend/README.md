# Quizly Backend API

NestJS service that orchestrates the Quizly onboarding consultation with Google Cloud Vertex AI Agent Runtime (Reasoning Engine).

---

## 1. Endpoints & API Contract

### `POST /quiz/submit-answer`
Submits questions asked so far and returns the next diagnostic question generated by the Vertex AI Reasoning Engine, or `nextQuestion: null` when the quiz is complete (8 questions, capped by MAX_QUESTIONS in app.service.ts).

- **Request Body**: `AnsweredQuestionDto[]` (Array of answered questions)
- **Response**: `NextQuestionResponseDto` (`{ nextQuestion: QuestionDto | null }`)

#### DTO Definitions ([`src/quiz.dto.ts`](file:///Users/illia.kazachkovskyi/Documents/Illia%20Project/quizly/apps/backend/src/quiz.dto.ts))

```typescript
export const QUESTION_TYPES = ['singleChoice', 'multiChoice'] as const;
export type QuestionType = (typeof QUESTION_TYPES)[number];

export class QuestionDto {
  question: string;
  answers: string[];
  typeOfQuestion: QuestionType;
}

export class AnsweredQuestionDto extends QuestionDto {
  selectedAnswers: string[];
}

export class NextQuestionResponseDto {
  nextQuestion: QuestionDto | null;
}
```

#### Example Usage

**Start Survey (Turn 1):**
```bash
curl -X POST http://localhost:3000/quiz/submit-answer \
  -H "Content-Type: application/json" \
  -d '[]'
```

**Submit Answers (Turn 2):**
```bash
curl -X POST http://localhost:3000/quiz/submit-answer \
  -H "Content-Type: application/json" \
  -d '[
    {
      "question": "Is your face longer than it is wide, or about equal?",
      "answers": ["Noticeably longer than wide", "About equal"],
      "typeOfQuestion": "singleChoice",
      "selectedAnswers": ["Noticeably longer than wide"]
    }
  ]'
```
